# Wuwatappo Native

[![Build](https://github.com/DanielToyama/WuwaTappoNative/actions/workflows/build.yml/badge.svg)](https://github.com/DanielToyama/WuwaTappoNative/actions/workflows/build.yml)

WuwaTappo 1.0.2（库洛《鸣潮》官方桌宠）的 Windows 原生复刻实现，使用 C# / WinForms / WebView2 编写，不依赖官方客户端或任何补丁版运行时。

- 桌宠：GDI+ 分层窗口（`UpdateLayeredWindow`），逐像素 alpha，无闪烁。
- 主面板：WebView2 承载本地 HTML/CSS/JS，负责背包、图鉴、合成、预设、联机与设置。
- 网络：`HttpClient` + 手写 Socket.IO v4 / Engine.IO v4 客户端。
- 目标：**功能与原版一致，界面大致相同**，不追求逐像素复制。

> 本项目与库洛游戏无任何关联。游戏素材（角色、配件、表情、UI 图标）版权归库洛游戏所有。
> 仓库随附的少量素材仅用于保证构建结果一致，不构成本项目对素材的任何授权，详见 [NOTICE.md](NOTICE.md)。

本版本（0.0.9）亮点：

- **联机动作更跟手（对齐官方 1.0.3）**：本地每次敲击/点击都立即发送 `rc`，不再 40ms 丢包；接收端支持服务端批量包里的 `id1|id2`，逐个触发挥手；低负载立即上屏，人多时按时间预算集中重绘。
- **手部绘制层级**：角色贴图仍在名字/数量 UI 后面，但手臂/手部会单独覆盖在 HUD 上，拍桌效果不再被计数条或昵称条挡住。
- **Token 提取器**：独立的单文件图形工具，不需要 Python/pip；自动检测并关闭官方客户端，解密后一键复制 token。
- **面板适配各种分辨率**：面板按桌宠所在显示器的 DPI/工作区缩放并夹紧，小屏和 125%/150% 缩放下不会再超出屏幕；窄窗口会自动折叠侧栏、堆叠列表。
- **只允许一个实例**：重复启动不会再生一个托盘/桌宠进程，而是把已运行实例的面板唤到前台。
- **首次启动自动声明**：免责声明未确认时，启动会自动打开面板并弹出声明，不需要手动找设置。
- **坐标恢复更准**：联机成员桌宠靠近屏幕顶部/边缘时，按实际可见区域恢复位置，不再被上方 130px 的透明气泡净空向下推。
- **新成员摆放**：新进房间的成员桌宠从当前屏幕右下角开始，占位就向左挪，排满后向上换行，并避开本机桌宠。
- **输入统计更完整**：键盘与鼠标左/右键都计入点击数，设置面板打开时继续统计；点面板/桌宠按钮不会重复计数。
- **悬停淡出更稳**：鼠标停留 500ms 后才进入半透明，只是划过桌宠不会闪一下；主桌宠和联机成员都按此规则。
- **Windows 通知可关**：自动领宝箱、快捷键动作的托盘通知分别有开关，不再只能全开或全关。
- **管理员程序下也能统计**：可选用管理员权限启动；Windows UIPI 下普通权限无法接收管理员前台窗口的按键。
- **面板一定到前台**：从桌宠/托盘打开设置时窗口会真正获得焦点，不会只显示在背景。
- **人多场景性能优化**：44 人房间全员每秒按键 10 次的压测下约占单核 6.7%，动作不再排队；拖动角色时键盘只移动不重绘。
- **自动宝箱**：每 30 秒检查左右宝箱，解锁满 5 秒自动领取，到点前先同步云端点击数。
- **设置全会同步**：不透明度、悬停半透明、置顶、鼠标穿透对所有联机成员桌宠一起生效。
- **快捷键可改**：默认对齐官方 Helper（F5/F7/F8/F9、Ctrl+Alt+1~6），支持录制、清除、冲突检测，保存即生效。
- **开机自动启动**：设置里一键开关（当前用户 Run 项），启动时自动与注册表对齐。
- **快捷键不抢键**：用 Raw Input 被动监听，不注册系统热键、不装键盘钩子，其他程序照常收到 F5/F7 等按键，也不增加按键延迟。
- 完整功能与实测数据见 [本版本特色](#本版本特色009)。

## 构建

要求：Windows 10/11 x64、[.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)。

```powershell
dotnet build -c Release
# 产物：bin\Release\net8.0-windows\WuwatappoNative.exe
```

运行还需要 **WebView2 Runtime**（Win10/11 通常已内置；缺失时面板无法显示，桌宠仍可用）。

发布自包含版本（不要求目标机器安装 .NET Runtime）：

```powershell
dotnet publish -c Release -r win-x64 --self-contained true `
  -p:DebugType=none -p:DebugSymbols=false -o publish/app-0.0.9
```

> 说明：执行过上面这条 `publish -r win-x64` 之后，`bin\Release\net8.0-windows\win-x64\`
> 里会出现一整套自包含运行时文件。它是 RID 专用构建的中间产物（MSBuild 在带 `-r` 时会多算一遍），
> 不是源码，也不是发布目录，可以直接删除；真正的发布产物在 `publish\app-0.0.9\`。

## 运行

首次运行会在 `%LOCALAPPDATA%\WuwatappoNative\` 创建：

- `config.json`：登录 token、外观、缩放/透明度、快捷键、房间历史等；
- `log.txt`：运行日志；
- `cache/`：外观目录与图片缓存。

首次启动会自动打开主面板并显示免责声明；点击「我已知晓」后才会记录。程序只允许一个实例：再次运行会唤起已运行实例的面板，不会重复创建托盘/桌宠进程。面板会按当前显示器的 DPI 和工作区自动缩放，窄屏下侧栏与设置项会自动折叠/换行。

登录方式（面板 → 设置）：

1. **UID + 验证码**（官方主路径）：输入游戏 UID（9~10 位）或账号绑定手机号（11 位），点「发送验证码」，填入 6 位验证码登录。
2. **导入 token**：可用仓库配套的 [Token 提取器](token-extractor/README.md) 从本机官方客户端提取 `kuro_infoToken`，再粘贴到设置里导入。

> 手机号登录依赖官方短信通道；实测该通道暂未开放，目前请使用游戏 UID 登录。

### 快捷键（默认值与官方 Helper 一致，可在设置里修改）

| 功能 | 默认键 |
|---|---|
| 游戏模式（鼠标穿透）开关 | `F7` |
| 切换屏幕 | `F8` |
| 显示 / 隐藏桌宠 | `F9` |
| 刷新界面 | `F5` |
| 发送表情槽位 1~6 | `Ctrl+Alt+1` ~ `Ctrl+Alt+6` |

`F5`/`F7`/`F8`/`F9` 与表情快捷键都支持录制修改、清除（禁用）与冲突检测，保存后立即生效。

### 开发参数

```powershell
WuwatappoNative.exe --panel           # 启动即打开主面板
WuwatappoNative.exe --demo            # 面板跳过登录门槛（只读页面预览）
WuwatappoNative.exe --leave-room      # 维护：退出当前房间后关闭
WuwatappoNative.exe --set-skin 1046   # 维护：登录后切换本地皮肤并热重载
WuwatappoNative.exe --verbose         # 额外调试日志
WuwatappoNative.exe --stress 30 --stress-hz 10
                                      # 本地伪造 30 个成员、每秒 10 次按键，用于人多场景压测（不联网）
```

## 本版本特色（0.0.9）

### 面板分辨率、单实例与首次启动

- **按 DPI/工作区自适应**：面板以 1120×780 DIP 为设计尺寸，按桌宠所在显示器 DPI 换算后夹到工作区；小屏不会越过任务栏，高缩放也不会被裁掉。
- **窄屏 CSS**：窗口较窄时侧栏收窄、背包/联机双栏改为上下堆叠，设置项自动换行；竖向空间不足时页签区域独立滚动。
- **单实例**：用命名 Mutex 阻止第二个进程；再次启动会通过命名事件让已运行实例打开面板并置前，不再出现多个托盘图标。
- **首次启动自动声明**：`DisclaimerShown` 未确认时启动即打开面板并弹出免责声明；确认后才会记住。

### 联机动作延迟与层级

- **低延迟上屏**：远端按键动作到达后，若当前没有重绘积压就立即绘制；高峰期改为每 16ms 最多用 10ms 集中处理，避免固定“每帧 6 个窗口”造成动作排队。
- **与官方 1.0.3 的 `rc` 语义一致**：本地每次有效敲击立即 `emit("rc")`，不做 40ms 节流；远端支持 `rc {"a":"id1|id2|..."}` 的批量动作包，按 `|` 拆分后逐个触发对应成员。
- **手部置顶**：角色身体/头部仍在名字与计数 UI 后面；只把手臂帧在 HUD 的裁剪区域内再画一次，手指和拍击动效会覆盖计数条/昵称条。
- **性能实测**：44 名成员、每秒 10 次全员按键的压测下，占用单核约 6.7%，无动作积压。

### 输入统计与设置面板
- **鼠标也算按键**：Raw Input 被动接收鼠标左/右键，与键盘一样计数、挥手并点亮桌面键盘上的鼠标键。
- **不重复计数**：点在设置面板、标题栏、桌宠菜单或联机成员桌宠上的鼠标操作不会计入全局统计；点桌宠本体仍只记一次。
- **设置面板不中断统计**：面板打开、拥有前台焦点时键盘统计继续；只有光标在文字输入框里时才暂停，避免把输入 UID/兑换码算成点击。
- **面板自动到前台**：桌宠窗口是 `WS_EX_NOACTIVATE`，旧实现只 `Show()` 时不会激活。现在会临时附加前台输入线程并 `SetForegroundWindow`，从桌宠计数器或托盘打开设置都会真正获得焦点。
- **焦点标记不会卡住**：面板隐藏、失焦或页面重新聚焦时都会同步一次输入焦点状态，关闭设置后不会出现“统计再也不涨”的假死。

### 悬停半透明延迟

鼠标停留 500ms 后才淡出，只是划过桌宠不会闪一下透明度；离开立即恢复。主桌宠和每个联机成员桌宠都按各自的停留时间计算。

### 通知开关

设置页新增「通知」：

- **宝箱领取通知**：自动领取成功后是否发 Windows 托盘通知；
- **快捷键操作通知**：F5 刷新、F7 游戏模式等快捷键动作是否发托盘通知。

面板内的消息提示不受影响，关闭后只是不再弹 Windows 通知。

### 管理员权限启动（可选）

Windows 的 UIPI 决定了普通权限进程无法接收“以管理员身份运行”的前台程序发来的 Raw Input，这是安全边界，不能靠钩子绕过。设置页「其他 → 以管理员权限启动」会请求 UAC 并重启程序；当前已经是管理员时会显示状态。开启后开机自动启动也会在登录时请求 UAC，请按需使用。

### 人多场景性能优化

几十人的联机房间里，远端桌宠和事件都按人数线性增长，这里做了四层收敛：

- **事件分流**：成员按键只驱动对应桌宠的挥手动画，不再触发房间状态全量推送与名册刷新。
- **推送合并**：面板的房间状态推送按帧合并，房间页再用内容签名去重，内容没变就不重建 DOM。
- **重绘调度**：所有远端桌宠共用一个 16ms 调度器；无积压时动作立即绘制，有积压时按时间预算批量处理，状态没变的成员不重绘。
- **零拷贝后缓冲**：每个分层窗口用 DIB Section 直接作画，不再每帧 `GetHbitmap` 拷贝整幅位图；窗口位图复用，避免高频分配。
- **拖拽不再烧 CPU**：拖动角色时键盘只移动不重绘，几何更新节流到 60Hz。

实测：44 名成员、每秒 10 次全员按键的压测下约占单核 6.7%，动作无积压；拖动角色时键盘只移动不重绘。压测入口：`WuwatappoNative.exe --stress 44 --stress-hz 10`（只在本机伪造，不联网、不影响服务器）。

### 自动宝箱

- 每 30 秒检查左右宝箱时间戳，解锁满 5 秒自动领取，失败 60 秒后重试。
- 到点前先刷新一次云端点击数，避免用过期余额判断导致开箱被拒。
- 领取成功弹奖励弹窗 + 托盘通知；可手动点击宝箱按钮提前查看。
- 关闭「总是显示宝箱」时只露出可领取按钮，悬停桌宠时临时显示两侧倒计时。

### 设置对所有联机成员生效

不透明度、悬停半透明、窗口置顶、鼠标穿透不再只作用于主角：

- 悬停淡出按窗口各自生效：鼠标在谁身上、停留满 500ms，谁才变淡；
- 其余三项会同步应用到同屏所有成员桌宠，改了立刻生效。

### 自定义快捷键

- 默认键位与官方 Helper 一致：`F7` 游戏模式（鼠标穿透）、`F8` 切换屏幕、`F9` 显隐桌宠、`F5` 刷新界面、`Ctrl+Alt+1~6` 表情槽位。
- 设置页可点击录制新组合键，支持清除（禁用该功能）、恢复默认与冲突检测；
- 保存后立刻生效，不用重启；快捷键改动的开关状态会实时反映回设置页。
- **高亮跟手**：键盘按键高亮由 Raw Input 边沿直接驱动（不等轮询），每次按下至少亮 70ms，
  快速点按不会“一闪就没”；主角挥手/计数重绘合并到约 60fps，面板点击数推送 100ms 节流，连打不会卡住。
- **不占用按键**：通过 Raw Input（`RIDEV_INPUTSINK`）被动接收按键，不调用 `RegisterHotKey`、也不安装低级键盘钩子。
  其他程序仍能收到 F5/F7/F8/F9 等按键，输入路径上没有任何额外处理，不会增加按键延迟。
  代价是这些键在前台程序里也会照常生效（例如浏览器 F5 仍会刷新）；如果某个组合与常用软件冲突，可在设置里改键或清除。

### 界面与体验

- **最近获得**常驻独立页签，新物品自动插入最前，重启不丢，可一键清空记录。
- 联机页常驻**历史房间**，支持直接点选切换；切换会先退出当前房间再进入。
- 合成栏按稀有度分成三行，最高稀有度不再被挤到另一行。
- 图鉴/背包里设置表情时，槽位预览图标尺寸修正。
- 缩放档位扩到 25% / 50% / 75% / 100% / 125% / 150% / 200%。
- 首次启动弹出免责声明；设置里有「关于」，包含版本、作者、鸣谢与 GitHub 链接。
- **开机自动启动**：设置里一键开关，写入当前用户的 `HKCU\...\Run`（不需要管理员，不改系统级启动项）；
  启动时会与注册表对齐，手动删掉启动项或换过安装目录都会自动修正。

### 桌宠与键盘

- 桌宠：272×331 逻辑像素，眨眼、拖动方向反馈、左右手交替按键动画；表情轮盘与气泡参数对齐原版（1s 生命、上浮 102px、70% 后淡出）。
- 桌面键盘 / 手柄：26 键、鸣潮专属、XInput 手柄面板；手柄按键与键盘走同一条计数/广播链路（按任意键都会计数、广播、挥手），摇杆只做显示不计数，避免转摇杆被当成按键。
- 远端桌宠：皮肤下载完成前不显示昵称条，避免先出现空白窗口；加载失败会回落到默认帧。新成员默认从当前屏幕右下角开始，位置被占用时向左移动，排满后向上换行（本机桌宠也占位）。恢复位置时按猫和昵称条的可见区域判断，窗口上方透明的气泡净空允许超出屏幕。手部帧在昵称条上单独置顶显示。

## 已知限制

- 手机号登录依赖官方短信通道，当前实测不可用，请使用游戏 UID 登录。
- 未实现自动更新器；安装包需手动下载替换。
- 官方客户端的 App-Bound Encryption（v20）cookie 无法解密，请使用 UID + 验证码登录。
- 普通权限进程无法接收管理员前台窗口的全局输入（Windows UIPI）；需要该场景时请在设置里开启「以管理员权限启动」，开启后每次启动（含开机启动）都会请求 UAC。
