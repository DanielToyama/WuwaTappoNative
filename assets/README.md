# assets 目录

本目录随仓库分发，用于保证任何人克隆后编译出来的程序与作者本机的运行效果一致。

| 路径 | 内容 | 用途 |
|---|---|---|
| `default/role_1501_1001_head_1.png` | 默认角色头帧（睁眼） | 未登录 / 加载失败时的桌宠 |
| `default/role_1501_1001_head_2.png` | 默认角色头帧（眨眼） | 眨眼动画 |
| `default/role_1501_1001_body_1.png` | 默认角色身体（静帧） | 桌宠静止 |
| `default/role_1501_1001_body_2.png` | 默认角色身体（左手） | 向左拖动 / 按键 |
| `default/role_1501_1001_body_3.png` | 默认角色身体（右手） | 向右拖动 / 按键 |
| `ui/chest-btn.png` | 可领取宝箱按钮底图（84×60） | 宝箱锚点 |
| `ui/chest-countdown.png` | 宝箱倒计时气泡底图（196×99） | 宝箱剩余时间 |
| `app.ico` | 多尺寸应用图标（16/24/32/48/64/128/256px 独立帧） | exe / 快捷方式 / MSI / 面板任务栏 / 托盘 |

角色图片提取自官方 WuwaTappo 1.0.2 客户端，版权归库洛游戏所有。
`app.ico` 使用默认角色头帧与本项目品牌色圆角底合成，每种尺寸单独绘制，避免托盘图标被透明留白缩小。
随仓库提供**仅为保证构建结果一致**，不构成本项目对素材的任何授权；请勿单独提取再分发或用于商业用途。
详见仓库根目录 [NOTICE.md](../NOTICE.md)。

在线运行时角色 / 配件 / 表情图片仍从官方 CDN 下载，缓存到
`%LOCALAPPDATA%\WuwatappoNative\cache\images`，不写入程序目录。
