01 — FEATURES

已经实现的功能

保留原版在线内容和联机体验，同时把桌宠、登录、直播采集和多人排列做成了更适合桌面长期使用的原生版本。

01 / ONLINE◇

联机与账号

  • 支持原版全部在线内容与联机
  • 支持国服与国际服（Global）切换与官方登录继承
  • 支持国服手机号 + 短信验证码登录（库洛通行证）
  • 支持一键继承官方登录状态
02 / LOOK✦

外观与互动

  • 支持自定义所有皮肤
  • 支持发送任意表情（无视拥有状态、无视角色限制，他人可见）
  • 支持本地微调头饰位置
  • 支持自动领取宝箱
03 / PLAY⌘

桌面玩法

  • 支持自动表情、自动敲击和游戏模式规则
  • 支持快捷键
  • 支持显示当前键盘/手柄键位（含鸣潮专属键位）
  • 音游模式支持 4K / 5K / 6K，每个模式分别保存键位
  • 支持刷 Key 数量（一键 +10000）
04 / MULTI◌

多人体验

  • 支持联机角色自动避让、横向/纵向排列与重置排序
  • 多人联机保存每一个人的位置，掉线、重进、重启软件都保持原位
  • 支持主播模式 OBS 采集窗口，自定义背景色或透明背景
02 — WHY NATIVE

为长时间挂桌面而做的细节

不是简单套一层网页壳：桌宠窗口、点击账本、多人位置和直播采集都按长时间运行场景处理。

80 MB vs 650 MB

更轻的同屏占用

12 人同屏场景下，官方版本约 650 MB，本版本约 80 MB，长时间挂着更安心。

100% 位置记忆

每个人都在原位

联机成员的位置独立保存；对方掉线、重新进房，或你重启软件，都不会把所有人打回默认位置。

OBS 采集窗口

独立采集窗口

使用独立可采集窗口，自定义采集分辨率和背景色，也可以使用透明背景；支持兼容模式回退，首次开启会提示 OBS 选择 Windows 10 采集方式，避免把整个桌面或低画质画面推给直播软件。

04 — GET STARTED

三步开始使用

下载发布包，登录账号，然后创建或加入房间。Setup 安装版和 portable 绿色版都可以直接使用。

01 / DOWNLOAD

下载安装包

从 GitHub Releases 下载 Setup 安装包；也可以使用 portable ZIP 解压即用。发布包自包含，不需要安装 .NET 8 Runtime。

02 / LOGIN

登录账号

在面板选择国服或国际服，使用 UID、手机号，或直接继承本机官方 WuwaTappo 的登录状态。

03 / PLAY

创建或加入房间

打开「联机」创建房间或输入房间号。联机桌宠会按当前横向/纵向排列方案自动就位。
